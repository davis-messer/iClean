# iClean App
A simple iOS app that lets you quickly sort through your photos by swiping left (delete) or right (keep).

## Features
- Swipe right to keep a photo
- Swipe left to delete a photo
- Import new photos from your photo library
- Intuitive UI with haptic feedback
- Smooth animations

## Requirements
- iOS 15.0+
- Xcode 13.0+
- Swift 5.5+

## Setup Instructions
1. Open the project in Xcode
2. Select your development team in the project settings
3. Add a new "App Group" capability if you want to save the sorted photos
4. Build and run the app on your device or simulator

## How to Use
1. Grant photo library access when prompted.
2. Select which photo to start sorting from.
2. Swipe right on photos you want to keep (also bottom right "keep" button).
3. Swipe left on photos you want to delete (also bottom left "delete" button).
5. Press the bottom "menu" button and press "trash" in the pop-up menu to delete the photos marked 
   for deletion.
